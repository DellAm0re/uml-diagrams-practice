## Важливі уточнення

- В UML-діаграмі класів `Проходження дисципліни` — окремий клас, який фіксує реєстрацію студента на дисципліну та оцінку.
- UML object diagram показує **знімок об'єктів**, а не часовий процес. Тому діаграма Дарвіна відображає об'єкти двох поколінь та їхні зв’язки, але не повну динаміку еволюції.
- Діаграма станів води є спрощеною фізичною моделлю: перехід залежить не лише від нагрівання, а й від тиску.
- Файли візуалізовано за допомогою Graphviz і SVG; це схематичні UML-діаграми, не експорт із UML CASE-засобу.
